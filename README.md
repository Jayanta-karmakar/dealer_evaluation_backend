# Product API - Java Spring Boot Project

This project is a Java Spring Boot implementation of a Product API that was originally built using Node.js and Python. The goal of this project was to convert the existing APIs into a Java Spring Boot application, maintaining the same functionality and structure.

---

## Project Status

- **80% Complete**: The core functionality has been implemented, including the following APIs:
    - `GET /api/products` - Returns a list of all products.
    - `GET /api/getdealers/{product}` - Returns the list of dealers for a specific product.
    - Additional APIs (`/price/{dealer}/{product}` and `/allprice/{product}`) are partially implemented and can be completed upon request.
